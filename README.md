# 大栄鉄塔クライム (DAIEI TOWER CLIMB)

React + TypeScript + Three.js + Cloudflare Workers / R2 で構築された、スマートフォン・PC対応の3レーン3Dエンドレスクライミングアクションゲームです。

## 実装済み機能（Phase 1〜8 完了）

1. **Phase 1：3D鉄塔と無限上昇基盤**
   - 後方カメラ視点、プレイヤーを画面中央下付近に固定し、鉄塔（18区間オブジェクトプーリング＋`InstancedMesh`）が下方向へ無限スクロール。
   - 描画FPS（30/60/120/144fps）に依存しない固定60Hzステップ（`FixedClock`）の決定論的シミュレーション。
2. **Phase 2：操作と基本アクション**
   - PC（`← →` / `A D` 移動、`↑` / `W` / `Space` ジャンプ、`↓` / `S` スライド、`Esc` 一時停止）
   - スマートフォン（スワイプ操作および画面下部タッチコントロール）
   - 障害物接触時のゲームオーバー判定とワンタップ即時再挑戦。
3. **Phase 3：コイン・4種障害物・段階的難易度**
   - **4種類の障害物**：
     1. `beam_low`（下部鉄骨・梁：ジャンプで回避）
     2. `beam_high`（上部看板・梁：スライドで回避）
     3. `missing_foothold`（足場の欠損：ジャンプまたはレーン変更で回避）
     4. `moving_load`（周期移動する吊り荷・可動鉄骨：タイミングを見て安全レーンを通過）
   - **強風エリア（`wind_zone`）**：高度80m以降で発生。事前予告バナーと3D風粒子を表示し、一定時間ごとに横方向へ1レーン押し流す（風単体での即死はなく、障害物への誘導要因として機能）。
   - **スコア計算**：`有効獲得コイン枚数 × 到達高度(整数m)`、コイン重複取得防止、高度に応じた段階的加速と最高速度上限。
   - **回避可能経路の保証**：すべての行に必ず通過可能な安全レーン（`safeLane`）と回避アクション（`safeAction`）を保証。
4. **Phase 4：特殊アイテム4種類と高度別4段階背景**
   - **特殊アイテム（各10秒＝600ステップ、同種再取得で10秒リセット、異種同時発動対応）**：
     1. `magnet`（コインマグネット：全3レーンのコインを吸引）
     2. `double`（コイン2倍：取得コインの有効枚数が2倍）
     3. `slow`（スローモーション：FPS非依存で上昇速度を減速）
     4. `high_jump`（ハイジャンプ：ジャンプ高度・滞空時間アップ、上部梁も飛び越え可能）
   - **高度別背景**：
     - `0〜100m`：街並み・緑・工事現場
     - `100〜300m`：青空・雲・霧
     - `300〜500m`：夕焼け・雲海
     - `500m〜`：宇宙・星・流星・地球の輪郭（鉄塔は現実的な鉄骨トラス構造を維持）
5. **Phase 5：画面とサウンド**
   - スタート画面、初回限定チュートリアル、プレイHUD（高度・コイン・スコア・アイテム残り時間バー・強風警告）、一時停止・画質/音量設定、ゲームオーバー画面、Web Audio APIプロシージャル音源＋外部MP3/WAV差し替え機構。
6. **Phase 6：週間ランキング＆サーバー側リプレイ検証**
   - 日本時間（JST）毎週月曜0:00切替の週間固定コース（シード値共有）。
   - クライアントから送信された操作履歴（`tick`, `action`）をサーバー側（`worker/index.ts` / `verifyRunReplay`）で完全再現してスコアを再計算し、改ざんスコアや不正履歴を拒否。
   - ニックネーム未登録時は非公開の仮記録として保存し、ニックネーム登録後に週間TOP100（1〜3位表彰台＋4〜100位一覧＋自己ベスト固定バー）へ公開。

## ローカル起動・テスト・ビルド方法

```bash

npm run dev

# 自動テスト実行 (Vitest)
npm test

# 本番ビルド
npm run build
```
