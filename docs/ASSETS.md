# 大栄鉄塔クライム — 自作素材（画像・3Dモデル・音源）制作指示書 (`docs/ASSETS.md`)

本書は、「大栄鉄塔クライム (DAIEI TOWER CLIMB)」において、現在のプログラム内蔵の仮素材（Three.js プロシージャルメッシュおよび Web Audio API 合成音）から、**ユーザー制作の本番素材へ差し替えるために必要な全ファイル仕様**をまとめた制作指示書です。

> **現在の動作状態について**
> 自作素材が未配置の状態でも、ゲーム内の仮素材（3Dプリミティブモデル・CSS/テキストUI・Web Audio合成サウンド）によって全機能が正常に動作するようフォールバック設計されています。制作が完了したファイルから順次、指定の保存フォルダへ配置してください。
